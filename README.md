# Vincent - Don McLean

This is my final assignment for my Software and Web Developer course. I created a simple webpage about the song "Vincent" by Don McLean using ASP.NET Core and Visual Studio 2022.

## Features

- Introduction to the song
- Information about the song
- A simple and easy-to-use webpage

## Purpose

The purpose of this project is to practice my basic web development skills and learn how to create a webpage using ASP.NET
